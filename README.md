# Genius Skies

A low-poly flight game in the browser: colossal world wonders, monuments to great minds, six aircraft, and an uninvited starship.

Play: https://bfreak-art.github.io/genius-skies/

- `index.html` is the whole game (the only file that changes for normal updates).
- `sw.js` keeps a copy on the phone for instant, offline launches. Bump `VERSION` only when `three.min.js` or the icons change.
- `three.min.js` is three.js r128 (MIT licence).
